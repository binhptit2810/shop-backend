# E-commerce UI Rules

## General

This project is an e-commerce website.

When modifying or creating frontend UI:

- Follow the frontend-design skill.
- Do not create generic AI-generated interfaces.
- Do not use purple gradients as the default visual identity.
- Do not overuse rounded cards.
- Do not use glassmorphism by default.
- Do not use excessive shadows.
- Do not use Inter as the default font unless there is a design reason.
- Do not create repetitive card grids without a UX reason.

## Product UI

Product cards must prioritize:

1. Product image
2. Product name
3. Price
4. Rating
5. Purchase action

Product imagery must be visually dominant.

## Layout

- Desktop and mobile must both be considered.
- Do not simply shrink desktop layouts for mobile.
- Maintain clear visual hierarchy.
- Use consistent spacing.
- Avoid excessive empty decorative elements.

## Interaction

- Buttons must clearly communicate their action.
- Hover states should be subtle and intentional.
- Animations must have a UX purpose.
- Respect reduced-motion preferences.

## Before coding

For significant UI changes:

1. Analyze the existing design.
2. Define the visual direction.
3. Identify reusable components.
4. Implement the UI.
5. Inspect the result in the browser.
6. Fix visual inconsistencies.
